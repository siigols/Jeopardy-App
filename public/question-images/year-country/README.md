Static images for the seeded `yearCountryImage` questions, which are authored in code
(`src/data/`) rather than in the board editor.

How to reference an image in one of those questions:

- Use a path starting with /question-images/year-country/
- Example: /question-images/year-country/world-cup-final-1.jpg

Tip:

- Keep filenames lowercase and use dashes.

Images for boards built in the editor do not go here — they are uploaded through the
editor itself and stored in the database. See the "Images" section of the root README.
